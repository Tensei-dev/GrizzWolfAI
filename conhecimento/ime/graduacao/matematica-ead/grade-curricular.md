# Grade curricular

Ressaltamos que é de suma importância que todos os alunos leiam o Projeto Pedagógico para que tomem nota das atividades acadêmicas necessárias para a conclusão do curso, haja vista que, além do cumprimento das disciplinas obrigatórias previstas para cada modalidade será necessário o cumprimento de atividades complementares e trabalho de conclusão de curso, ambos descritos no Projeto Pedagógico.

Veja a Grade Curricular do Curso de Graduação em Matemática, grau Licenciatura, modalidade a distância Turma 2 e Turma 3.
